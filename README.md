LogiTalk Stickers
LogiTalk Stickers (LogiTalk Stickers Realization) — мережевий чат-клієнт на Python та CustomTkinter. Підтримує зміну нікнеймів через анімоване меню, обмін текстовими повідомленнями, а також швидку відправку зображень та графічних стікерів за допомогою кодування Base64 через протокол TCP.
